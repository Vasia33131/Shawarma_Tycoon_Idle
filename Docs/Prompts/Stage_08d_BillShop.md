# Этап 08d — Магазин: покупка купюр и обмен на монеты

## Цель
Есть магазин, где игрок:
- покупает паки купюр за реальные деньги (на Яндексе — за «яны»);
- меняет купюры на мешки монет.

## Контекст
- Уже готово:
  - `BillWallet` (08c);
  - `IPlatformService.Purchase(productId, onComplete)` — в редакторе заглушка (`EditorPlatformService`), реальные покупки Яндекса — этап 09;
  - `StationController.IncomePerSecond`, `Wallet`;
  - `TabBar` (4 вкладки), `GameUiBuilder`.
- Цены монет должны расти вместе с игроком. Поэтому мешок монет = **N минут текущего дохода** (минимум — фиксированная сумма × масштаб города), а не фиксированное число.

## Файлы
- Создать:
  - `Shop/BillShopConfig.cs` (SO):
    - паки купюр: `productId`, количество купюр, бонус-метка «выгодно», цена для отображения в редакторе;
    - мешки монет: цена в купюрах, минуты дохода, минимум;
  - `Shop/BillShop.cs` — чистый C#:
    - `TryBuyCoins(index)`: считает награду, списывает купюры, начисляет монеты;
    - `BuyBillPack(index, onDone)`: зовёт `IPlatformService.Purchase` и начисляет купюры **только** при успехе;
  - `UI/ShopPanel.cs`, `UI/BillPackRowView.cs`, `UI/CoinPackRowView.cs`;
  - тесты `Tests/EditMode/BillShopTests.cs`.
- Изменить:
  - `GameUiBuilder`: **5-я вкладка «Магазин»** (решение пользователя) с секциями «Купюры» и «Монеты»; тап по счётчику купюр в HUD открывает эту вкладку (`TabBar.Select`);

## Задачи (по порядку)
1. Конфиг + `BillShop` + тесты (не хватает купюр → ничего не меняется; награда ≥ минимума при нулевом доходе; покупка не прошла → купюр нет).
2. UI магазина: строки с ценой и наградой; награда мешка пересчитывается при открытии вкладки и раз в секунду.
3. Звук покупки, вылет монет / купюр к счётчику в HUD.
