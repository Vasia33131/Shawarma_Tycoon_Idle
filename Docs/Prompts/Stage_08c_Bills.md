# Этап 08c — Донатная валюта «Купюры»

## Цель
В игре появляется вторая валюта — купюры. Она видна в HUD, сохраняется и **не сбрасывается** при переезде в новый город. Тратить её научим на этапах 08d–08f.

## Контекст
- Уже готово:
  - `Wallet` (монеты, город), `PrestigeState` (живёт в Boot, переживает переезд);
  - `HudView` (монеты, доход, репутация);
  - `SaveService`, `ISaveParticipant`, `SaveMigrator`.
- Купюры — валюта игрока, а не города, поэтому живут в Boot рядом с `PrestigeState`.

## Файлы
- Создать:
  - `Economy/BillWallet.cs` — чистый C#: `long Bills`, `Add(long, BillSource)`, `TrySpend(long, BillSink)`, событие `Changed`. Источник и цель трат — enum для будущей аналитики;
  - `Save/BillsSave.cs`, `Economy/BillsSaveParticipant.cs`;
  - тесты `Tests/EditMode/BillWalletTests.cs`.
- Изменить:
  - `SaveData`: `Bills` (по умолчанию 0);
  - `GameBootstrap`: регистрация;
  - `PrestigeController.TryPrestige`: убедиться, что купюры не трогаются;
  - `HudView` + `GameUiBuilder`: счётчик купюр (зелёная иконка-банкнота) рядом с репутацией; по тапу открывается магазин (до этапа 08d — заглушка);
  - `strings.txt`: `bills.name` («Купюры» / «Bills»).

## Задачи (по порядку)
1. `BillWallet` + тесты (нельзя уйти в минус, отрицательные суммы игнорируются, событие только при изменении).
2. Сейв + миграция (старые сейвы → 0) + тест round-trip.
3. HUD: счётчик и анимация «+N» при начислении.
4. Debug-меню: «Add 100 Bills».

## Критерии приёмки
- [ ] Компилируется без ошибок и warnings; тесты зелёные.
- [ ] Купюры переживают перезапуск и переезд в новый город.
- [ ] PROGRESS.md обновлён.

## НЕ делать на этом этапе
- Магазин, покупки, рекламу.
