# Этап 08a — Звук и фоновая музыка

## Цель
В игре слышны звуки и играет фоновая музыка. Есть отдельный звук заработка денег и звук нажатия на кнопки.

## Контекст
- **Почему сейчас тихо (диагностика):**
  - ни в `Boot.unity`, ни в `Game.unity` нет `AudioListener`: `ProjectSetupTool.CreateCamera` создаёт камеру без него. Без слушателя Unity не воспроизводит ни один звук;
  - музыки в коде нет вообще: `AudioService` умеет только короткие `PlayOneShot`.
- Уже готово:
  - `Core/Audio/`: `AudioService`, `AudioConfig`, `SoundEntry`, `SoundId`;
  - звуки Kenney в `Assets/_Game/Audio/*.ogg`;
  - `ButtonFeedback` играет `_sound` при нажатии;
  - `CoinFlyEffect` играет `SoundId.Coin`;
  - `ContentSetup.EnsureAudioConfig` создаёт `Audio.asset` только если его нет.
- `AudioService` создаётся в сцене Game (`GameSceneInstaller`) и пересоздаётся при переезде. Музыка должна жить в Boot и не прерываться при перезагрузке сцены.

## Файлы
- Создать:
  - `Core/Audio/MusicService.cs`: один `AudioSource` с loop на `DontDestroyOnLoad`-объекте, `Play(AudioClip)` с плавным переходом, `Volume`, `Muted`, пауза на `GameEvents.GamePaused`;
  - `Core/Audio/MusicConfig.cs` (SO): трек по умолчанию, громкость, длительность фейда; опционально трек на город.
- Изменить:
  - `ProjectSetupTool` / `GameUiBuilder`: добавить `AudioListener` на Main Camera в Boot (один на всю игру; в Game камеру без слушателя, чтобы не было двух);
  - `GameBootstrap`: зарегистрировать `MusicService`, тикать фейд через `TickManager`;
  - `SoundId`: + `Cash` (звук заработка), при необходимости `Click` вместо `Tap`;
  - `ContentSetup`: записать новые клипы в `Audio.asset`. Важно: существующий ассет не перезаписывается — нужен шаг «добавить недостающие записи».
- Ассеты. **Решение пользователя:** источники — CC0 (OpenGameArt, Kenney) или Pixabay Music. Каждое скачивание отдельно подтвердить: имя файла, ссылка, размер:
  - `Assets/_Game/Audio/Music/` — 1–2 зацикливаемых трека (лицензия CC0 или Pixabay, OGG Vorbis, моно или стерео ≤ 96 kbps, ≤ 1.5 МБ каждый);
  - звук «дзынь»/кассы для заработка и мягкий клик для кнопок.
- Импорт: музыка — `Streaming`, `Vorbis`, quality 50–60; короткие звуки — `Decompress On Load`.

## Задачи (по порядку)
1. Добавить `AudioListener` (сцены + инструмент сборки сцены), проверить, что текущие звуки заиграли.
2. Скачать треки и звуки (источник, имя файла и размер — согласовать с пользователем до скачивания). Положить рядом файл `Assets/_Game/Audio/LICENSES.md`: что, откуда, лицензия.
3. `MusicService` + `MusicConfig`: старт после `GameReady`. Браузер не даёт звук до первого клика — запуск по первому вводу, если `AudioSource` не играет.
4. Звук заработка: на завершении цикла станции (`StationController.Earned`) с ограничением частоты (`MinInterval` ≥ 0.15 с), отдельно от звука прилёта монет.
5. Звук нажатия — на всех кнопках через `ButtonFeedback` (проверить, что у всех кнопок сборщика он есть).

## Критерии приёмки
- [ ] Компилируется без ошибок и warnings.
- [ ] Ровно один `AudioListener` в любой момент игры.
- [ ] Музыка играет по кругу и не обрывается при переезде в новый город.
- [ ] Во время рекламы и при потере фокуса музыка и звуки на паузе.
- [ ] Лицензии записаны в `Audio/LICENSES.md`.
- [ ] Размер аудио в билде ≤ 3 МБ.
- [ ] PROGRESS.md обновлён.

## Ручная проверка в Unity
1. Setup Project / Build Game UI → Play из Boot: музыка звучит, клик по кнопке слышен, станция «дзынькает».
2. Переезд через Debug → Add City Threshold Earned: музыка не прерывается.
3. Alt+Tab: тишина, возврат — продолжается.

## НЕ делать на этом этапе
- Выключатели звука в UI (этап 08b), отдельные треки на каждый город — только если пользователь попросил.
