# Этап V3 — Вечерняя сцена города и нарисованный ларёк

> **ДО запуска:** положить пакет C в `Assets/_Game/Sprites/Scene/City0X/` и `Scene/Common/`, пакет D в `Assets/_Game/Sprites/Kiosk/` (см. `Docs/Visual/ASSET_PROMPTS.md`), открыть Unity и дождаться импорта.

## Цель
Над списком станций — живая картинка: закатное небо, силуэт узнаваемого города, уличные детали по краям, тёплый свет от ларька на тротуаре. Ларёк нарисован, а не собран из прямоугольников. У каждого города своё настроение. Сцена работает в портрете и ландшафте.

## Контекст
- Прочитай `Docs/Visual/ART_DIRECTION.md` (таблица «Вечер по городам») и пакеты C и D в `Docs/Visual/ASSET_PROMPTS.md`.
- Уже готово:
  - V1: `UiTheme`, `Sprites/UI/Generated/glow_soft.png`; V2: `ArtAssigner` (меню `ShaurmaTycoon/Art/Assign Icons`);
  - `Prestige/CityConfig.cs`: `_skyColor`, `_boothColor`, `_mapPosition`; переезд в город — `PrestigeController`;
  - `Customers/KioskView.cs`: `_sky`, `_boothTinted[]`, `_seller`, `_spit` + `_spitStripes` (иллюзия вращения), `_window`, `_managerDecor[]` (6 украшений по числу менеджеров, порядок: гирлянда, меню-доска, столик под зонтом, рамка вывески, цветы, флаги), `_levelLamps[]`;
  - `GameUiBuilder.BuildKiosk`, `BuildKioskDecor`, `BuildPlant`, `BuildStreet` — текущий процедурный ларёк и улица (константа `GroundRatio = 0.2`);
  - `UI/ResponsiveLayout.cs`: зона ларька в портрете 1080×520 под HUD, в ландшафте — левая половина экрана (~960×700);
  - `SpriteImportSettings`: max 512 по умолчанию.
- Ограничения: картинки фона **накрывают** зону целиком (cover), выравнивание по низу, лишнее обрезает маска зоны; без аллокаций в `Tick`; текстуры неба создаются только при смене города, не каждый кадр; при отсутствии спрайтов — текущий процедурный вид (старый код не удалять, а оставить как запасной путь) и одно предупреждение со списком.

## Ручная проверка в Unity (для меня)
1. `ShaurmaTycoon/Art/Assign Icons` (теперь назначает и фоны) → `Build Game UI` → Play.
2. Смотрю 10 секунд, ничего не нажимая: небо-закат, слои еле заметно «дышат», лампы мягко мерцают.
3. Debug-меню → «Hire Next Manager» ×6: украшения появляются по одному.
4. Debug-меню → переезжаю по всем 5 городам: каждый город узнаётся по силуэту.
5. Переключаю Game view в 1920×1080: сцена слева, без дыр.

## Решения
- Ассеты пришли без имён в корне `Assets/`: опознаны по содержимому, разложены и почищены (подробно — PROGRESS.md, «Этап V3»). Фоны квадратные, а не 3:2 — обрезаны по содержимому и по линии улицы; `decor_flags` добавлен позже — две гирлянды по бокам ларька (над ларьком перекрыла бы вывеску).
- Задача 5 (кроссфейд при переезде) заменена плавным проявлением сцены при загрузке: переезд перезагружает сцену Game, двух наборов слоёв одновременно не бывает.
- Слои — по ширине зоны на линии тротуара, а не cover: при квадратных картинках cover в портрете закрывал бы всё небо.
- Тонируются корпус и навес; столик под зонтом — нет (тонировка перекрасила бы и дерево).
- Виньетка не сделана: края зоны уже затемняют тени шапки и вкладок (V1).
- Ларёк из картинок строится, если есть `kiosk_body`; иначе — прежний процедурный (код сохранён).
