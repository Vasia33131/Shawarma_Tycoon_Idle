# Этап V2 — Иконки интерфейса и станций

> **ДО запуска:** положить пакет A в `Assets/_Game/Sprites/UI/Icons/` и пакет B в `Assets/_Game/Sprites/Stations/City01…City05/` (см. `Docs/Visual/ASSET_PROMPTS.md`), открыть Unity и дождаться импорта.

## Цель
Вместо цветных кружков с буквами — нарисованная еда у каждой из 30 станций; у вкладок, валют и кнопок — понятные иконки. Игрок узнаёт всё по картинке, без чтения.

## Контекст
- Прочитай `Docs/Visual/ART_DIRECTION.md` и таблицы пакетов A и B в `Docs/Visual/ASSET_PROMPTS.md` — там точные имена файлов.
- Уже готово:
  - этап V1: `UiTheme`, `SoftButton`, процедурные спрайты в `Sprites/UI/Generated/`;
  - `Stations/StationConfig.cs` уже имеет поле `_icon` (Sprite), сейчас оно пустое во всех 30 ассетах `Configs/Stations/City0X/`;
  - строки со значком станции: `StationRowView`, `ManagerRowView`, `UpgradeRowView` (поля `_icon` — Image-кружок, `_iconLabel` — буква), строятся в `GameUiBuilder.BuildRowIcon`;
  - HUD: `HudView` (`_coinIcon`, репутация, купюры); `RetentionHud` (подарок, календарь, задания, буст); `TabBar`; `SettingsPopup` (шестерёнка собрана из кружков); `OfflineIncomePopup`; `QuestRowView`; `TutorialHand`; иконки товаров магазина (`Sprites/Shop/`) уже подключены — их не трогать;
  - `Editor/SpriteImportSettings.cs` — все PNG из `Sprites/` → спрайт, max 512.
- Ограничения: назначение спрайтов в ассеты — **редакторским кодом по пути** (`AssetDatabase.LoadAssetAtPath`), а не правкой YAML с выдуманными GUID; если файла нет — оставить текущую заглушку и вывести **одно** предупреждение со списком недостающих путей; без аллокаций в `Tick`.

## Файлы
- Создать `Scripts/UI/Theme/UiIcons.cs` — SO: поля-спрайты для каждого файла пакета A (`Coin`, `Bill`, `Reputation`, `Income`, `TabStations`…`TutorialHand`).
- Создать `Configs/UiIcons.asset`.
- Создать `Scripts/Editor/ArtAssigner.cs` — меню `ShaurmaTycoon/Art/Assign Icons`: заполняет `UiIcons.asset` из `Sprites/UI/Icons/` и `StationConfig._icon` из `Sprites/Stations/<папка города>/<имя ассета станции>.png`; печатает отчёт «назначено N, не найдено: …». Вызывается и из Build Game UI.
- Изменить: `SpriteImportSettings.cs` (папки `Sprites/UI/Icons/` и `Sprites/Stations/` → max 256, сжатие Normal Quality), `GameUiBuilder.cs`, `StationRowView.cs`, `ManagerRowView.cs`, `UpgradeRowView.cs`, `HudView.cs`, `TabBar.cs`, `SettingsPopup.cs`, `OfflineIncomePopup.cs`, `QuestRowView.cs`, `TutorialHand.cs`, `RewardIconView.cs` (если там рисуются монеты/купюры), `ContentSetup.cs`.

## Ручная проверка в Unity (для меня)
1. `ShaurmaTycoon/Art/Assign Icons` → в консоли «назначено 30 станций, 21 UI-иконка».
2. `Build Game UI` → Play. Пролистать все вкладки: везде еда, у вкладок иконки.
3. Debug-меню → дойти до Казани: у станций казанская еда.
4. Закрытая станция — тёмный силуэт с замком; открываю — силуэт «проявляется».

## Решения
- Пакет A пришёл без имён (`Assets/image-45641….png`): иконки опознаны по содержимому, почищены (убрана нарисованная «шахматка» у подарка и телевизора, бахрома у звезды и чашки), обрезаны и сохранены 512×512 под именами из ASSET_PROMPTS. Пакет B (30 станций) пришёл позже в `Assets/new/` — разложен так же, у чурчхелы убрана «дымка» фона.
- Тест «у каждого поля UiIcons есть строка в ArtAssigner» не написан: тестовая сборка не видит редакторский код. Вместо него `StationIconsTests` проверяет, что имена файлов в `Sprites/UI/Icons` и `Sprites/Stations` — известные (опечатка в имени = тест красный).
- «Силуэт» закрытой станции — светлый полупрозрачный «призрак» картинки (настоящая заливка требует шейдера); при открытии значок делает punch, а не проявление цвета.
- `icon_close` — на кнопках «Закрыть», а не отдельным крестиком в углу попапа.
