# Этап V5b — Нарисованная карта филиалов и иконки магазина

> **ДО запуска:** сгенерировать пакет I по `Docs/Visual/ASSET_PROMPTS.md`: `Sprites/Map/` (`map_bg`, `map_city_01..05`, `map_van`, `map_pin`) и `Sprites/Shop/coins_small/medium/large.png`. Открыть Unity и дождаться импорта. Без картинок этап всё равно должен работать: остаётся нынешняя карта из примитивов.

## Цель
Карта во вкладке «Город» сейчас выглядит как черновик: зелёный прямоугольник, кружки-«деревья», голубой овал вместо озера, прямые пунктиры, серые кружки с цифрами. Она должна стать **нарисованной картой путешествия** в стиле игры. Каждый город — узнаваемая миниатюра, дорога — извилистая тропа, фургон-ларёк едет по ней. Хочется, чтобы игроку захотелось «доехать» до следующего города.

## Ручная проверка в Unity (для меня)
1. `Art/Assign Icons` → `Build Game UI` → Play → вкладка «Город».
2. Тапаю по каждому городу: плашка сверху меняется, ореол выбора на нужном городе.
3. DEV → +1B несколько раз: фургон едет по кривой к следующему городу, штрихи закрашиваются.
4. Поворачиваю экран (ландшафт): карта не обрезает города, подписи на месте.
5. Вкладка «Магазин»: у всех строк картинки.

## НЕ делать на этом этапе
- Новые города, маршруты, награды за «путешествие».
- Анимацию облаков над картой и смену дня/ночи на карте (можно в V7).

## Решения
- `map_bg` пришёл квадратным: обрезан до 1024×780, карта стала выше (`MapHeight` 760, карточка 1110), чтобы все поляны помещались под плашкой.
- С фоном область городов = картинка целиком (FitInParent), а не область с отступами: `MapPosition` — доли картинки, т. е. центры полян; на широком экране поля закрывает тот же фон «на обрез», затемнённый. Так города не съезжают с полян и не обрезаются при любой ширине.
- Города разложены по полянам с учётом географии: Сочи — у моря, Питер — у снежных гор; маршрут остаётся зигзагом.
- Пульс следующего города — на общем `Content` (кружок или миниатюра), а не на кружке; масштаб текущего — на `Body`, они не конфликтуют.
- Штрихи у миниатюр не рисуются (`_nodeClearance`), фургон стартует и финиширует у края миниатюры — доля кривой считается по её длине, а не константой.
- Ширина ленточки подписи — по `GetPreferredValues` в `SetName` (вызывается только при смене языка), без `ContentSizeFitter`.
- Иконки магазина (`Sprites/Shop`) импортируются как иконки (256): крупнейшая — стартовый набор, 210 px.
