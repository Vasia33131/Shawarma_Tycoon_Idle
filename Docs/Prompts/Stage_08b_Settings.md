# Этап 08b — Настройки (звук и музыка)

## Цель
Кнопка-шестерёнка в HUD открывает окно настроек: можно отдельно выключить звуки и музыку. Выбор сохраняется.

## Контекст
- Уже готово:
  - `AudioService` (звуки, сцена Game), `MusicService` (музыка, Boot) — этап 08a;
  - `HudView`, `GameUiBuilder` (попапы по образцу `OfflineIncomePopup` / `PrestigeConfirmPopup`);
  - `SaveService` + `ISaveParticipant`, `SaveMigrator`.
- Настройки — общие для игры, не для города: живут в Boot и не сбрасываются при переезде.

## Файлы
- Создать:
  - `Core/Settings/GameSettings.cs` — чистый C#: `SoundOn`, `MusicOn`, событие `Changed`;
  - `Save/SettingsSave.cs`, `Core/Settings/SettingsSaveParticipant.cs`;
  - `UI/SettingsPopup.cs` — два переключателя и кнопка «Закрыть».
- Изменить:
  - `SaveData`: поле `Settings` со значениями по умолчанию «всё включено» (старые сейвы без поля → включено);
  - `GameBootstrap`: регистрация `GameSettings` и participant;
  - `AudioService` / `MusicService`: читать `GameSettings`, реагировать на `Changed` без перезапуска сцены;
  - `GameUiBuilder`: кнопка-шестерёнка в HUD (слева сверху, симметрично репутации), попап;
  - `strings.txt` + `StringsFileTests.RequiredKeys`: `settings.title`, `settings.sound`, `settings.music`, `settings.on`, `settings.off`, `settings.close`.

## Задачи (по порядку)
1. `GameSettings` + сейв + тесты: по умолчанию включено, round-trip, старый JSON без поля.
2. Подключение к звукам и музыке: выключенная музыка ставится на паузу (а не останавливается), включённая продолжается с того же места.
3. UI: шестерёнка, попап, переключатели (вкл — зелёный, выкл — серый), звук нажатия играет только если звуки включены.

## Критерии приёмки
- [ ] Компилируется без ошибок и warnings; тесты зелёные.
- [ ] Выключенные звук/музыка остаются выключенными после перезапуска и переезда.
- [ ] Окно открывается и закрывается в портрете и ландшафте.
- [ ] PROGRESS.md обновлён.

## Ручная проверка в Unity
1. Выключить музыку → тишина, звуки слышны; выключить звуки → клики не слышны.
2. Перезапуск Play → настройки сохранились.

## НЕ делать на этом этапе
- Смену языка, ползунки громкости, сброс прогресса (если пользователь не попросил).
