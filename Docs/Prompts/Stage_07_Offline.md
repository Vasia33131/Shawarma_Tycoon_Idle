# Этап 07 — Офлайн-доход

## Цель
Пока игрока не было, станции с менеджерами зарабатывали. При входе появляется окно «Пока тебя не было: +X» с кнопками «Забрать» и «Забрать ×2» (rewarded). Время ограничено лимитом, перевод часов назад ничего не даёт.

## Контекст
- Уже готово:
  - `Save/SaveService` (`Data.SavedAtUtcTicks` — время последнего сохранения, `SaveNow`);
  - `Core/GameSceneInstaller` (сейв применяется в Awake);
  - `StationController.IncomePerSecond` (только станции с менеджером, с учётом апгрейдов и вех);
  - `IPlatformService.ShowRewarded`, `ServerTimeUtc`;
  - эффекты `CoinFlyEffect`, `TweenRunner`; сборщик `GameUiBuilder`.
- Разделы GDD:
  - §6: `доход/сек × время отсутствия × 0.5`, только станции с менеджером;
  - §6: лимит 2 ч (до 8 ч за репутацию — магазин репутации, этап 08);
  - §6: окно «Пока тебя не было: +X», кнопки «Забрать» и «Забрать ×2» (rewarded);
  - §8: «Офлайн ×2 — Rewarded — при входе».
- Ограничения:
  - числа — в `BalanceConfig`;
  - реклама только через `IPlatformService`;
  - тексты через `Loc`;
  - логика тестируется.

## Ручная проверка в Unity (для меня)
1. Найми менеджера, запомни доход/сек в HUD, Stop.
2. `ShaurmaTycoon → Save → Shift Save Time −1 h` → Play: окно с суммой = доход/сек × 1800.
3. «Забрать ×2» → монеты ×2 прилетели в HUD.
4. Stop → «Shift Save Time −3 h» → Play: «2 ч» и пометка лимита.
5. Выбери Build Game UI перед первой проверкой (появилось новое окно).
