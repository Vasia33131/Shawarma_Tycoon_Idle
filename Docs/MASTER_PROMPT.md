## Технические правила
- Unity **2022.3 LTS** (или 6000.x LTS), 2D, платформа **WebGL**.
- Код в `Assets/_Game/Scripts/`, namespace `ShaurmaTycoon.*`. Один файл — один класс.
- Все числа баланса — в **ScriptableObject-конфигах**, не в коде.
- Большие числа — `double` + форматирование `1.2K / 3.4M / 5.6B / 7.8T / aa / ab…`.
- Платформа (реклама, сохранения, лидерборды, покупки, язык) — **только через `IPlatformService`**. В редакторе — `EditorPlatformService` (реклама сразу «досмотрена», сохранения в PlayerPrefs). Игровой код не знает про Яндекс.
- Без `FindObjectOfType` и аллокаций в Update; обновление через общий TickManager.
- Плагины: только TextMeshPro, DOTween (free), Unity Test Framework, PluginYG2 **или** свой jslib-мост к Yandex SDK (решаем на этапе 09).
- Тексты UI — через локализацию (ru/en) с самого начала.
- UI проверять в портрете 1080×1920 **и** ландшафте 1920×1080.
