# Релиз на Яндекс Играх — «Шаурма Тайкун» (этап 12)

Требования сверены с https://yandex.ru/dev/games/doc/ru/concepts/requirements (октябрь 2026).

## 1. Сборка

1. Unity → `ShaurmaTycoon/Art/Build Sprite Atlases` (если не выполнялось после V7) → `ShaurmaTycoon/Build Game UI`.
2. `ShaurmaTycoon/Release/Build Yandex (WebGL)` — сам переключит платформу на WebGL, выставит релизные настройки, проверит пункты модерации (Preflight) и соберёт в `Builds/Yandex`.
   - Архив для консоли: `Builds/Yandex.zip` (`index.html` в корне архива — п. 1.22), его собирает `YandexRelease`.
   - Отчёт о размере: `Builds/Yandex_size_report.txt` (файлы билда + 40 самых тяжёлых ассетов + разбивка по типам).
3. Без открытого редактора:
   ```
   "C:\Program Files\Unity\Hub\Editor\2022.3.62f1\Editor\Unity.exe" -batchmode -quit -projectPath C:\Users\diman\idle -buildTarget WebGL -executeMethod ShaurmaTycoon.EditorTools.YandexRelease.BuildFromCommandLine -logFile Builds\build.log
   ```

### Что сделано для размера (цель < 20 МБ)
| Что | Было | Стало |
|---|---|---|
| Managed stripping (WebGL) | Minimal (плагин выставлял при каждой сборке) | High + `Assets/_Game/link.xml` (сборка ShaurmaTycoon целиком) |
| PluginYG2 (2,4 МБ в проекте, ядро и 3 `.jslib` в билде) | в проекте | удалён: SDK — шаблон + свой мост |
| IL2CPP | по умолчанию | Code Generation = OptimizeSize, Master |
| Стек в логах | для всех типов | Log/Warning — без стека, ошибки — ScriptOnly |
| Сжатие | Brotli | Brotli, без decompression fallback |
| Запасной трек `HappyClappyLoop.wav` (6 МБ) | в билде через `Music.asset` | файл удалён из проекта: запасной трек = `music_cozy_01` (у всех 5 городов своя музыка) |
| Мёртвые файлы | SampleScene, шаблон сцены URP 2D (3,9 МБ), PDF TMP, материалы LiberationSans Drop Shadow/Outline в `Resources` | удалены (ни одной ссылки по guid, пути или имени) |
| Музыка | quality 0.5, Streaming | quality 0.35 (lo-fi), Decompress On Load — Web Audio, без системного плеера (1.6.1.6, 1.6.2.5) |
| Эмбиент (улица, море, ветер, дождь, гриль) | стерео, 0.45 | моно, 0.3 (на WebGL Unity всё равно кодирует AAC ~128 кбит/с — quality и моно размер не меняют) |
| **Музыка и эмбиент** | 11,2 МБ в стартовом `.data` (Unity на WebGL кодирует любой клип в AAC ~128 кбит/с, quality и моно не влияют) | **4,7 МБ, вне стартового файла**: свои MP3 в `Assets/StreamingAssets/Audio` (музыка 64 кбит/с стерео, эмбиент 40 кбит/с моно 32 кГц) — меню `ShaurmaTycoon/Release/Encode Web Audio (MP3)` (нужен ffmpeg, для сборки — нет). Игра догружает нужный файл после старта (`AudioClipStore`, распакованный клип → Web Audio); первый город ~1,5 МБ. Preflight проверяет, что MP3 есть |
| Post-processing URP (FilmGrain ×10, SMAA, UberPost — ~3 МБ) | `Renderer2D` ссылался на PostProcessData, хотя на камерах post-processing выключен | ссылка снята (`m_PostProcessData: {fileID: 0}`) |
| Шрифт LiberationSans SDF (статический атлас 1 МБ в `Resources`) и EmojiOne (341 КБ) | всегда в билде через `Resources` | удалены: запасной шрифт Rubik — динамический `LiberationSans SDF - Fallback` (тот же TTF), emoji в игре нет |
| Заставка «Made with Unity» (2,7 МБ) | — | остаётся: на лицензии Personal для Unity 2022 не отключается |
| Шрифт Rubik SDF (динамический) | атлас 1024² из редактора в билде | атлас очищается при сборке, глифы строятся из TTF |
| Текстуры | — | уже V7: DXT5 Crunched, атласы, фоны quality 50 |

Исключения оставлены `FullWithoutStacktrace`: режим «только явные» превращает любой NullReferenceException в падение всей игры (п. 1.14), а большая часть этапов ещё не гонялась в Unity.

**PluginYG2 удалён из проекта (2026-10-06).** SDK подключается только в шаблоне `WebGLTemplates/YandexGames/index.html` (`/sdk.js` → `YaGames.init()` → `createUnityInstance`), вся работа с ним после старта — свой мост `Plugins/WebGL/YandexBridge.jslib` (этап 09): реклама, облачные сейвы, покупки, каталог цен, лидерборд, LoadingAPI, GameplayAPI, пауза, язык, серверное время. Шаблон больше не правится при сборке, архив собирает `YandexRelease`, символы `PLUGIN_YG_2; YandexGamesPlatform_yg; TMP_YG2` снимает `Apply WebGL Release Settings`. Preflight не даст собрать билд, если папка плагина вернётся или шаблон снова шлёт `YG2Instance`. Язык в редакторе — меню `ShaurmaTycoon/Editor Language`.

## 2. Консоль разработчика — до загрузки архива

- **Покупки** (раздел «Покупки», включить Payments). Id должны совпадать с `Configs/BillShop.asset`; товар, которого нет в каталоге, игра не показывает (п. 1.13.6). Картинки товаров 512×512 — `Assets/_Game/Sprites/Shop/`.

  | id | Тип | Цена, ян | Что даёт |
  |---|---|---|---|
  | `bills_small` | расходуемый | 19 | 20 купюр |
  | `bills_medium` | расходуемый | 99 | 120 купюр |
  | `bills_large` | расходуемый | 249 | 350 купюр |
  | `starter_pack` | постоянный (один раз) | 99 | 50 купюр + монеты на 50 купюр |
  | `no_ads` | постоянный | 149 | без межстраничной рекламы (rewarded остаётся по желанию) |
  | `income_x2` | постоянный | 299 | весь доход ×2 навсегда |

  Цена в игре берётся из каталога SDK (`getCatalog`: число + валюта портала, п. 1.13.2 / 1.13.4); цены в `BillShop.asset` — только запасные до ответа каталога.
- **Лидерборд**: техническое имя `richest`, название «Самая богатая сеть» / «Richest chain», тип — число, сортировка по убыванию.
- **Облачные сохранения** — включить в черновике (п. 1.11).
- **Языки**: русский, английский. Остальные языки интерфейса Яндекса игра показывает на английском.
- **Ориентация**: портретная и альбомная (вёрстка адаптивная). **Платформы**: десктоп, мобильные. TV — **не** отмечать (в игре есть покупки, п. 1.6.3.4).
- **Возрастной рейтинг**: 0+.

### Только вручную (черновик или устройство)

Номера в скобках — пункты требований. Если шаг не прошёл — не отправлять на модерацию, записать что видно (скриншот, текст из консоли браузера).

#### A. В Unity — перед сборкой
1. Переключиться в окно Unity и дождаться окончания импорта и компиляции (после удаления PluginYG2 и смены импорта музыки). В Console не должно быть красных ошибок.
2. `Window → General → Test Runner → EditMode → Run All` — все тесты зелёные.
3. `ShaurmaTycoon/Release/Apply WebGL Release Settings`, затем `Edit → Project Settings → Player → WebGL`:
   - Resolution and Presentation → WebGL Template — **YandexGames**;
   - Other Settings → Scripting Define Symbols — без `PLUGIN_YG_2`, `YandexGamesPlatform_yg`, `TMP_YG2`.
4. Если меняли музыку или эмбиент в `Assets/_Game/Audio/Music|Ambient` — `ShaurmaTycoon/Release/Encode Web Audio (MP3)` (MP3 в `Assets/StreamingAssets/Audio`). Load Type исходных клипов — Decompress On Load (Preflight проверит).
5. `ShaurmaTycoon/Release/Build Yandex (WebGL)`. В Console — `Preflight OK`, `Build OK`, `Archive for the developer console: Builds/Yandex.zip`.
6. Открыть `Builds/Yandex_size_report.txt`: строка TOTAL — сжатый размер; распакованный (сумма файлов в `Builds/Yandex` до Brotli) должен быть < 100 МБ (1.21).
7. Открыть `Builds/Yandex.zip` проводником: **в корне** `index.html`, `style.css`, папки `Build`, `Images`, `TemplateData` (если есть) — без вложенной папки сверху (1.22). В именах нет пробелов и кириллицы. **Нет `debugcheck.js`** (релизная сборка и Preflight это проверяют).

#### A2. Debug Checker — автопроверка перед модерацией (по желанию, перед шагами C)
Неофициальный чекер [yandex-games-debug-checker](https://github.com/Nioris/yandex-games-debug-checker) (MIT), лежит в `Tools/YandexDebugChecker` (версия и хеш — в его README). Вердикт советный: PASS не гарантирует модерацию, но FAIL по REQ — повод разобраться до отправки.
1. `ShaurmaTycoon/Release/Build Yandex Debug (checker)` → `Builds/YandexDebug`: те же настройки, что у релиза, но без сжатия и с `<script src="debugcheck.js">` сразу после `/sdk.js`. Архива нет — **эту сборку на модерацию не грузить**.
2. Запустить с настоящим SDK: `npx @yandex-games/sdk-dev-proxy` из папки `Builds/YandexDebug` с id игры из консоли (флаги — `npx @yandex-games/sdk-dev-proxy --help`); прокси откроет черновик на Яндексе, который грузит игру с localhost. Без `/sdk.js` (просто локальный сервер) большая часть проверок будет N/V.
3. Пройти сценарий: загрузка → первые покупки станций → rewarded за купюры → покупка в магазине → свернуть вкладку на 10 с → вернуться → смена языка (C9) → переезд с interstitial.
4. Панель: `Ctrl+Shift+2` три раза или `YGDebugChecker.open()` в консоли фрейма игры; после сценария — `YGDebugChecker.refresh()`. Отчёт копируется кнопкой в панели.
5. Разбирать FAIL и WARN класса **REQ**, HEURISTIC — по ситуации. Код SDK у нас в `Build/Yandex.framework.js` (мост `YandexBridge.jslib`), который статический разбор не читает (он смотрит только `<script>` из `index.html`) — статические FAIL вида «showFullscreenAdv/setData не найден» ложные; верить рантайм-проверкам (тайминг Game Ready, реклама после жеста, чтение `i18n.lang`).

#### B. Консоль разработчика — настройки (один раз)

У каждого — название и описание на русском и английском, совпадающие с тем, что игра выдаёт (раздел 2), картинка 512×512 из `Assets/_Game/Sprites/Shop/`. Цены — как в таблице.
2. **Лидерборд**: техническое имя `richest`, название «Самая богатая сеть» / «Richest chain», тип — число, по убыванию.
3. **Черновик → Загрузить** `Builds/Yandex.zip` (старый архив заменить, иначе модерация увидит прежний билд с системным плеером).
4. **Платформы**: десктоп ✓, мобильные ✓, **TV — не отмечать** (1.6.3.4). **Ориентация**: портретная и альбомная.
5. **Языки** (2.14): только **русский** и **английский**. Лишний язык в списке — модерация проверит и его, а игра покажет его на английском.
6. **Облачные сохранения** — включить (1.11).
7. Возраст 0+, категории и тексты — раздел 3; иконка, обложка, скриншоты — раздел 3 «Медиа» (8.3: без рамок, скруглений, интерфейса Яндекса).

#### C. Черновик на компьютере (Chrome или Яндекс Браузер)
Открыть черновик из консоли, сразу нажать F12 → вкладки **Console** и **Network**, затем обновить страницу (F5), чтобы видеть загрузку с начала.
1. **Загрузка** (1.1, 1.19.1, 6.4): виден вечерний экран загрузки с золотой полосой, затем игра. В Console нет красных ошибок от игры (`Build/…`, `YB:`, `Uncaught`). Ошибки расширений браузера и рекламных сетей Яндекса не наши — отличить по имени файла слева от ошибки.
2. **Только SDK** (1.7, 8.4): в Network фильтр `-yandex -yastatic` — запросов к чужим доменам нет; все файлы игры — с того же адреса, что и `index.html`.
3. **Game Ready** (1.19.2): игра открыта во фрейме — в Console слева вверху сменить контекст `top` на фрейм игры (адрес с `index.html`), выполнить `ysdk.features.LoadingAPI` — объект есть, `ysdk.environment.i18n.lang` — текущий язык. Игра показалась сразу после загрузки, без «вечного» экрана Яндекса поверх.
4. **Системный плеер** (1.6.2.5): включить звук, подождать 10 с музыки. Справа от адресной строки Chrome **не должно** появиться значка «Управление мультимедиа» (нота/плей), в панели медиа Chrome (иконка с нотой) нет вкладки игры. В Windows — нет плашки медиа у регулятора громкости.
5. **Фокус и звук** (1.3, 1.19.3): Alt+Tab в другое окно — звук стихает сразу, монеты перестают капать. Клик обратно в игру — звук и доход вернулись. Свернуть вкладку (перейти на другую вкладку на 10 с) — то же самое.
6. **Поле 2:1** (1.6.2.1, 1.6.2.2): сузить окно браузера по высоте до полосы (широкое и низкое) — поле игры по центру, не шире двух высот, по краям фиолетовый фон. Сделать окно узким и высоким — то же по вертикали. Окно почти квадратное и 4:3 — ничего не обрезано, тексты не налезают (1.10.1, 1.10.3).
7. **Меню и выделение** (1.6.2.7): правый клик по игре — меню браузера не открывается. Двойной/тройной клик и протяжка мышью по тексту — ничего не выделяется.
8. **Клавиатура** (1.6.2.4): игра управляется только мышью. F5, Ctrl+W и т. д. работают как обычно в браузере — игра их не перехватывает и своих не добавляет.
9. **Язык** (2.14): сменить язык Яндекса на English (в настройках аккаунта/портала или параметром `lang=en` в адресе черновика, если консоль его поддерживает) → обновить страницу → весь интерфейс на английском: вкладки, магазин, кнопки рекламы, попапы, обучение, офлайн-доход. Вернуть русский — всё на русском. Нигде не видно ключей вида `shop.title` и смеси языков.
10. **Сохранение** (1.9): купить уровень станции или улучшение → **сразу** F5 → покупка на месте, монеты списаны. Переключить звук в настройках → F5 → настройка сохранилась.
11. **Магазин** (1.13.2, 1.13.4–1.13.6): цены на кнопках — как в консоли, с валютой портала («ян»/«YAN»), без выдуманных значков. Выключить в консоли один товар → обновить черновик → строки этого товара нет.
12. **Покупка** (1.13.1): купить `bills_small` (в черновике оплата тестовая) → пришли 20 купюр. F5 → купюры на месте и **не начислены второй раз**. Купить `no_ads` → F5 → по-прежнему куплено.
13. **Rewarded** (4.5, 4.7): нажать кнопку купюр за рекламу (магазин) — открывается реклама Яндекса, звук игры молчит, доход стоит. Досмотреть — купюры пришли. Повторить и закрыть рекламу раньше времени — награды нет, игра продолжается. То же для «×2 доход», подарка и «Забрать ×2 за рекламу» в окне офлайн-дохода.
14. **Interstitial** (4.4): поиграть 3+ минуты, накопить на переезд, переехать в новый город — показывается межстраничная реклама, звук на паузе, после закрытия загружается новый город, прогресс на месте. Сразу второй переезд (если доступен) раньше 90 с — без рекламы.
15. **Назад/вперёд** (1.14): уйти со страницы черновика по ссылке/в адресной строке, нажать «Назад» — игра продолжает работать, звук вернулся после клика, ошибок в Console нет.

#### D. Черновик на телефоне (Android Chrome / Яндекс Браузер и iPhone Safari)
Открыть черновик на телефоне (ссылка или QR из консоли).
1. **Полный экран** (1.6.1.1): игра занимает весь экран, без полос и прокрутки страницы.
2. **Плеер в шторке** (1.6.1.6): включить музыку, подождать 10 с, опустить шторку уведомлений (Android) / открыть Пункт управления и экран блокировки (iPhone) — **плеера игры там нет**.
3. **Повороты** (1.14, 4.3): портрет → альбом → портрет прямо во время игры и во время открытого магазина/попапа — ничего не обрезано, не зависло, кнопки нажимаются.
4. **Сворачивание** (1.3, 1.14): свернуть браузер на 30 с и вернуться — звук был выключен, игра продолжилась, офлайн-доход посчитан.
5. **Долгий тап** (1.6.1.8): долго держать палец на тексте и на кнопке — не выделяется, не появляется меню «Копировать/Сохранить», лупа не появляется.
6. **Прокрутка** (1.10.2): свайп вниз от верха игры — страница не уезжает и не обновляется (нет pull-to-refresh). Списки станций/улучшений листаются внутри игры.
7. **Одна рука** (1.8, 1.10.4): в портрете на самом маленьком доступном телефоне все кнопки достаются большим пальцем, не мелкие, не перекрыты вырезом камеры и полосой жестов.
8. **Реклама на телефоне** (4.3, 4.7): rewarded в портрете и в альбоме — реклама показывается целиком, после неё игра в той же ориентации, звук вернулся.
9. **Второе устройство** (1.13.3): войти тем же аккаунтом Яндекса на ПК и на телефоне — прогресс с ПК есть на телефоне (облако пишется раз в 8 с и при сворачивании — сначала подождать 10 с на ПК, свернуть вкладку).
10. Повторить на телефоне шаг C9 (язык).
