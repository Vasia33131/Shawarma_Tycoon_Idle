# Визуал «Шаурма Тайкун»: дорожная карта

Цель: игра должна **расслаблять, и в неё должно хотеться вернуться**. Настроение: «уютный вечер у ларька».
Решения (2026-10-05): настроение cozy-вечер; стиль «казуал с обводкой», как у иконок магазина; фичи: живой фон, эмбиент, погода, кот.
Картинки генерируем в ChatGPT (GPT-image).

- Стиль, палитра, правила: [ART_DIRECTION.md](ART_DIRECTION.md)
- Промты для генерации картинок и список звуков: [ASSET_PROMPTS.md](ASSET_PROMPTS.md)
- Промты для нейросети-разработчика: `Docs/Prompts/Stage_V1…V7`

## Порядок работы

Каждый промт V1–V7 отдаётся нейросети-разработчику **по одному**, отдельным сообщением, после MASTER_PROMPT.
Перед некоторыми промтами нужно положить в проект свои файлы. Без них этап тоже соберётся, но останется старый плоский вид.

| # | Промт | Что делает | Что положить в проект ДО запуска |
|---|---|---|---|
| V1 | `Stage_V1_PaletteUiKit.md` | Вечерняя палитра, мягкие кнопки и панели (рисует код), спокойные анимации | Ничего |
| V2 | `Stage_V2_Icons.md` | Иконки вкладок, валют, кнопок и 30 станций | **Пакет A** (UI-иконки) + **пакет B** (иконки станций) |
| V3 | `Stage_V3_CityScene.md` | Фон города слоями с параллаксом, нарисованный ларёк и украшения | **Пакет C** (фоны 5 городов + облака) + **пакет D** (ларёк) |
| V4 | `Stage_V4_Characters.md` | Новые клиенты и продавец, кот Лаваш | **Пакет E** (6 листов: клиенты, продавец, кот — см. ASSET_PROMPTS) |
| V5 | `Stage_V5_LivingWorld.md` | Пар, птицы, машины, светлячки, дождь и снег, зонтики | **Пакет F** (машины, зонт, лужа) |
| V5b | `Stage_V5b_MapShop.md` | Нарисованная карта филиалов (миниатюры городов, изогнутая тропа, фургон), иконки мешков монет | **Пакет I** (карта, мешки монет) |
| V6 | `Stage_V6_Ambience.md` | Lo-fi музыка по городам, эмбиент улицы, дождь, мурчание | **Пакет G** (звуки) |
| V7 ✔ код | `Stage_V7_PolishRelease.md` | Режим любования, экран загрузки, атласы, проверка размера билда | `icon_zen.png` (из пакета A) + **пакет H** (по желанию) |

## Как класть файлы

1. Сгенерируй картинки по [ASSET_PROMPTS.md](ASSET_PROMPTS.md). **Имена файлов и папки — строго как в таблицах**: код ищет их по пути.
2. Положи файлы в указанные папки внутри `Assets/_Game/`.
3. **Открой Unity и дождись импорта** (появятся `.meta`). Только после этого запускай промт.
4. Если какой-то картинки нет, этап не сломается: на её месте останется текущая заглушка, а в консоли будет предупреждение со списком недостающих файлов.

## Чек-лист готовности картинки
- PNG, **прозрачный фон** (кроме фонов неба). Если ChatGPT нарисовал серую «шахматку» вместо прозрачности — прогони через remove.bg.
- Объект по центру, с отступом ~8% от краёв, ничего не обрезано.
- Без текста и букв на картинке (иначе не локализовать).
- Стиль совпадает с `Assets/_Game/Sprites/Shop/starter_pack.png`: прикладывай его как референс к каждой генерации.
