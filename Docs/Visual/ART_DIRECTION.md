# Арт-дирекция: «Уютный вечер у ларька»

## Зачем
Idle-игру открывают по 5–30 минут несколько раз в день. Чтобы человек возвращался, экран должен быть местом, где **приятно находиться**, а не только таблицей с цифрами. Опорные игры по ощущению: Cozy Grove, Unpacking, Good Pizza Great Pizza, вечерние сцены Animal Crossing.

## Пять правил
1. **Тёплый вечерний свет.** Небо — закатный градиент, в окнах горит свет, у ларька лампы и гирлянда. Никакого чисто-белого и кислотного.
2. **Мягкость.** Скруглённые формы, толстая тёмно-коричневая обводка (не чёрная), мягкие тени снизу. Без резких углов.
3. **Мир живёт сам.** Даже если игрок ничего не делает: пар идёт, облака плывут, кот дышит, мимо проезжает машина. Это и есть «залипательность».
4. **Спокойный ритм.** Анимации медленные, с плавным замедлением (ease-out). Пульсирует только одна главная кнопка-призыв, а не всё сразу. Звуки тихие и «круглые».
5. **Один стиль на всё.** Иконки, персонажи, фон и ларёк выглядят как из одной игры. Референс — `Assets/_Game/Sprites/Shop/starter_pack.png`.

## Анимации
- Нажатие кнопки: сжатие до 0.94 за 0.06 с, возврат с лёгким отскоком 0.18 с.
- Пульс CTA: амплитуда 0.04 (сейчас 0.06), скорость 2.5 (сейчас 5) — «дыхание», а не «тревога».
- Попапы: появление снизу + fade 0.25 с ease-out; затемнение fade 0.2 с.
- Монеты: лететь по дуге 0.6–0.8 с, звон тише и мягче.
- Всё фоновое (облака, машины, пар) — медленно, с разбросом скорости ±20%, чтобы не было «машинного» ритма.

## Чего избегать
- Чисто-чёрных обводок и теней (`#000`).
- Красного как основного цвета кнопок: он тревожит.
- Мерцания и вспышек на весь экран.
- Больше одного пульсирующего элемента одновременно (кроме подсказки туториала).
- Текста внутри картинок.

## Бюджет для WebGL (Яндекс Игры)
- Вся новая графика: **до +8 МБ** к билду после сжатия.
- Иконки: 256×256 (в Unity max 256). Персонажи: 512 по высоте. Слои фона: 2048 по ширине максимум, сжатие.
- Всё, что можно нарисовать кодом (кнопки, панели, свечение, капли дождя, пар), рисуем кодом, а не картинкой.
